# «Искусственная жизнь» — Java-приложение (Лабораторная работа 1)

Приложение на Java моделирует экосистему с логическими агентами:
растения (`P`), травоядные (`H`), хищники (`X`).

## Компиляция и запуск

```bash
cd src
javac *.java
java Main
```

По умолчанию запускается оконный интерфейс Swing. В нём доступны кнопки
«Старт», «Пауза», «Шаг», «Новая симуляция», выбор автоматического/пошагового
режима (`1 — пошаговый`, `2 — автоматический`, `3 — мгновенный итог`),
слайдер скорости, игровое поле,
счётчики популяций и настройки начального количества агентов и их энергии.
Также задаются ширина и высота поля, пороги размножения и энергия,
передаваемая потомку. Параметры применяются после нажатия «Сбросить поле».

Консольный режим запускается так:

```bash
java Main --console
```

В консольном режиме программа спросит:
1. Режим — `1` (пошаговый), `2` (автоматический) или `3` (мгновенный итог).
2. Максимальное число ходов (Enter — по умолчанию 500).

## Структура классов (соответствует ТЗ)

- **`Agent`** — абстрактный класс агента: координаты, энергия, символ,
  общие методы (`move`, `die`, `tryReproduce`/митоз, `wander`). Определяет
  абстрактные методы `act()`, `getMetabolism()`, `getReproductionThreshold()`,
  `getChildEnergy()`, `createChild()` — реализуются в наследниках
  (наследование + полиморфизм).
- **`Environment`** — пространственная модель: двумерная сетка со строгими
  границами,
  `getAgent/setAgent`, `getNeighbors(x, y, radius)` — зрение агента (radius=2
  даёт область 5×5), `getFreeNeighbor` — поиск места для потомка.
- **`Plant`** — не двигается, растёт из «солнца» каждый ход, размножается
  вегетативно в соседние клетки.
- **`Herbivore`** — двигается, зрение 5×5. Логика:
  *ЕСЛИ видит хищника → убегать; ИНАЧЕ ЕСЛИ видит растение → идти к нему и
  есть; ИНАЧЕ → блуждать случайно.*
- **`Predator`** — двигается, зрение 5×5. Логика:
  *ЕСЛИ видит травоядное → идти к нему и атаковать; ИНАЧЕ → блуждать
  случайно.* При погоне хищник иногда делает дополнительный «рывок»
  (`HUNT_SPEED`), а атака рядом с жертвой не гарантирована (`CAPTURE_CHANCE`) —
  иначе при равной скорости побег травоядного был бы успешен всегда.
- **`Simulation`** — игровой цикл: начальное заселение, обход всех агентов
  каждый ход, вывод в консоль, подсчёт популяций.
- **`Main`** — точка входа, выбор режима.

## Энергетическая модель

Новые агенты появляются только через естественное размножение существующих
агентов. Если энергия агента превышает видовой порог, родитель передаёт
потомку заданное количество энергии, а потомок появляется в соседней свободной
клетке. Искусственного подселения, миграции и вероятностного ограничения
размножения нет.

## Параметры (см. константы в классах)

| Параметр | Растение | Травоядное | Хищник |
|---|---|---|---|
| Метаболизм/рост (ΔE/ход) | +1 | -1.0 | -0.4 |
| Энергия от еды | — | +5 (растение) | +40 (травоядное) |
| Порог размножения | 80 | 1500 | 500 |
| Энергия потомка | 30 | 500 | 150 |

Размер поля настраивается в GUI отдельно по ширине и высоте,
границы поля являются строгими: выход за край и появление агентов
с противоположной стороны невозможны.
(от 5 до 200 клеток). Значения по умолчанию — 50×50 клеток.
Сбалансированная стартовая конфигурация: 200 растений, 5 травоядных
(начальная энергия травоядного — 40) и 1 хищник
(начальная энергия хищника — 400). Начальная энергия растения — 10.
